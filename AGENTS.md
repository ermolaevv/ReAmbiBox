# Workspace Guidelines & Agent Capabilities

Соблюдайте правила, описанные в [.agents/rules/capability-first.md](file:///.agents/rules/capability-first.md).

Перед выполнением любых задач обязательно сверяйтесь с реестром навыков:
- При написании или отладке кода на Rust активируйте `rust-router`, соответствующий модуль `m01`–`m15`, `unsafe-checker` и `coding-guidelines`.
- При работе с Windows API используйте `winapp-*`.
- При планировании и реализации задач используйте `openspec-*`.
- При исследовании кода используйте `codebase-memory-mcp`.
