# Design: Выборочное отключение отдельных горячих клавиш

## Context

В `crates/reambibox-app/src/hotkey_parser.rs` реализован парсинг строковых представлений клавиш в модификаторы и виртуальные коды Win32. 
В `crates/reambibox-app/src/tray.rs` функция `register_configured_hotkeys` регистрирует 4 действия. Перед регистрацией каждого действия вызывается `UnregisterHotKey`.
См. `proposal.md` для мотивации.

## Goals / Non-Goals

**Goals:**
- Позволить пользователю оставлять любое из 4 действий без назначенной горячей клавиши.
- При отсутствии комбинации корректно освобождать Win32-перехват клавиши (`UnregisterHotKey`), чтобы она была доступна другим программам.
- Добавить в Web UI удобные кнопки «✕» для мгновенной очистки поля ввода горячей клавиши, а также поддержку очистки клавишами Backspace и Delete.

**Non-Goals:**
- Изменение общего формата `config.json` (сохраняем обратную совместимость через строковые поля `""` / `"Отключено"`).
- Добавление сторонних хуков клавиатуры (используем стандартный Win32 `RegisterHotKey` / `UnregisterHotKey`).

## Decisions

### 1. Представление отключенного состояния
- **Решение**: Использовать пустую строку `""` (или `"Отключено"`) в полях `HotkeysConfig`.
- **Обоснование**: Полная обратная совместимость с существующей структурой конфигурации. Не требует усложнения схемы до `Option<String>` или добавления 4 дополнительных булевых полей.
- **Альтернативы**:
  - `Option<String>`: приводит к необходимости миграции старых конфигураций `config.json`.
  - Отдельные флаги `toggle_power_enabled: bool`: усложняет интерфейс и модель данных.

### 2. Логика в парсере и трее
- **Решение**: В `parse_hotkey(s: &str)` проверять `s.trim().is_empty() || s == "Отключено" || s.eq_ignore_ascii_case("none") || s.eq_ignore_ascii_case("disabled")` и возвращать `None`. В `register_configured_hotkeys` при `None` вызывать `UnregisterHotKey` и ничего не регистрировать.
- **Обоснование**: Гарантирует освобождение комбинации в Windows.

### 3. UX в Web UI
- **Решение**: Рядом с каждым инпутом `.hotkey-input` добавить кнопку с иконкой «✕» (`btn-clear-hotkey`). При клике на неё значение инпута меняется на `Отключено`. При сохранении (`POST /api/config`) значение отправляется как `""`. При получении конфигурации, если значение пустое или `"Отключено"`, в поле отображается `Отключено`.
- **Альтернативы**:
  - Чекбокс напротив каждой строки: занимает больше места в строке; кнопка «✕» компактнее и привычнее пользователям Windows/Discord.

## Risks / Trade-offs

- [Пользователь случайно очистит хоткей] → Кнопка «Сброс по умолчанию» восстанавливает стандартные комбинации (`Ctrl+Shift+A`, `Ctrl+Shift+Up`, `Ctrl+Shift+Down`, `Ctrl+Shift+O`).
