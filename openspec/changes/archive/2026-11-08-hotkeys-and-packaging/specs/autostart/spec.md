# Spec Delta: Автозапуск с ключом --minimized

## MODIFIED Requirements

### Requirement: Управление автозапуском через реестр Windows
Приложение SHALL / ДОЛЖНО поддерживать регистрацию исполняемого файла в системной ветке автозапуска `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` с аргументом фонового запуска.

#### Scenario: Включение автозагрузки
- **WHEN** пользователь включает опцию автозапуска в веб-панели управления или контекстном меню трея
- **THEN** в ключе реестра `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` создается строковый параметр `ReAmbiBox` со значением `"<путь к reambibox-app.exe>" --minimized`.

#### Scenario: Отключение автозагрузки
- **WHEN** пользователь выключает опцию автозапуска
- **THEN** параметр `ReAmbiBox` корректно удаляется из реестра без ошибок при его отсутствии.

#### Scenario: Чтение статуса автозагрузки
- **WHEN** веб-панель управления запрашивает статус конфигурации
- **THEN** система проверяет наличие параметра в реестре и возвращает актуальное булево значение.

#### Scenario: Тихий запуск с флагом --minimized
- **WHEN** приложение запускается операционной системой или пользователем с аргументом `--minimized`
- **THEN** процесс запускается полностью в фоновом режиме, не открывая окно консоли или вкладку браузера, и отображает иконку в системном трее Windows.

#### Scenario: Замещение предыдущего экземпляра процесса
- **WHEN** запускается новый экземпляр `reambibox-app.exe` при уже работающем в системе старом экземпляре
- **THEN** новый процесс находит старый экземпляр по имени процесса и идентификатору PID, молча завершает его, ожидает освобождения COM-порта и портов TCP 3637/3636, после чего продолжает запуск и занимает его место.
