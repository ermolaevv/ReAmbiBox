# Proposal: presets-management

## Why
Пользователи настраивают подсветку под разные сценарии (кино, игры, чтение, музыка). Ввод десятка параметров вручную при каждой смене занятия неудобен. Необходима система пользовательских профилей (пресетов) с возможностью сохранения текущей конфигурации под своим именем и быстрого переключения в 1 клик или через меню трея. Заводских пресетов не требуется — список формируется исключительно самим пользователем под его конкретные предпочтения.

## What Changes
- **Модель пресета (`Preset`)**: структура, хранящая снимок настроек подсветки (режим, яркость, сглаживание, гамма, насыщенность, баланс белого R/G/B, порог черного, letterbox, target_fps, аудио-эффект, чувствительность, статический цвет).
- **Пользовательские пресеты**: чистый список пресетов по умолчанию (без предустановленных заводских пресетов).
- **Управление пресетами**: возможность сохранять текущие настройки как новый пресет, обновлять существующий пресет и удалять любые созданные пресеты.
- **Быстрое переключение**:
  - В панели управления WebUI: переключатель пресетов и модальное окно сохранения/удаления.
  - В контекстном меню системного трея Windows: подменю «Пресеты» со списком и отметкой активного.
- **REST API эндпоинты**:
  - `POST /api/presets/apply` — применение пресета по имени/id.
  - `POST /api/presets/save` — сохранение текущих настроек в пресет с пользовательским именем.
  - `POST /api/presets/delete` — удаление пресета.

## Capabilities

### New Capabilities
- `presets`: хранение, переключение, создание и удаление пользовательских профилей конфигурации подсветки.

## Impact
- `crates/reambibox-core/src/config/mod.rs`: добавление структуры `Preset` и полей `presets: Vec<Preset>`, `active_preset: Option<String>` в `AppConfig`.
- `crates/reambibox-app/src/main.rs`: реализация API маршрутов `/api/presets/*` и синхронизация активного пресета с конвейером.
- `crates/reambibox-app/src/tray.rs`: добавление подменю пресетов в контекстное меню трея.
- `ui/index.html`, `ui/app.js`, `ui/style.css`: селектор пресетов, модальное окно сохранения и быстрое переключение.
