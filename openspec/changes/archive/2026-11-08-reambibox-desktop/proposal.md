# Proposal: Интеграция с рабочим столом Windows, системный трей и управление питанием

## Why

Сейчас ReAmbiBox работает как консольное приложение с открытым окном терминала. Для постоянного и комфортного повседневного использования программа должна функционировать как нативное фоновое приложение Windows: находиться в системном трее (Notification Area), управляться через контекстное меню, запускаться автоматически при старте системы, автоматически отключать подсветку при блокировке экрана (`Win + L`) или переходе монитора в спящий режим, а также гарантированно гасить светодиодную ленту при любом сценарии завершения работы программы.

## What Changes

- Добавлена интеграция с системным треем Windows (иконка в области уведомлений с цветным статусом активности).
- Реализовано контекстное меню трея: включение/выключение подсветки, выбор режима, открытие веб-панели управления, включение/выключение автозапуска, выход из приложения.
- Реализовано бесшовное скрытие консольного окна в релизной сборке (`#![windows_subsystem = "windows"]`) с возможностью запуска в режиме отладки через флаг `--console`.
- Реализовано управление автозапуском через реестр Windows (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
- Реализована обработка системных событий Windows (`WM_POWERBROADCAST`, `WTSRegisterSessionNotification`, `WM_ENDSESSION`): автоматическое выключение светодиодов при выключении монитора, блокировке ПК и завершении сеанса.
- Реализована гарантия полного гашения светодиодов при любом выходе из программы (Ctrl+C, меню трея, выключение ПК, паника) через обработчики сигналов и RAII guard.

## Capabilities

### New Capabilities
- `system-tray`: Фоновая работа в системном трее Windows с контекстным меню и индикацией статуса.
- `autostart`: Управление автозагрузкой приложения вместе с Windows через реестр.
- `power-management`: Отслеживание блокировки сессии, сна монитора и завершения сеанса для автоматического тушения и пробуждения светодиодной ленты.

### Modified Capabilities
- `device-output`: Добавлен гарантированный сброс подсветки в чёрный цвет при любом завершении процесса (Graceful & Panic Shutdown) и энергосберегающий режим.

## Impact

- Добавляются зависимости Windows API (`windows-rs` фичи `Win32_UI_WindowsAndMessaging`, `Win32_System_Power`, `Win32_System_RemoteDesktop`, `Win32_System_Console`).
- Обновляется `reambibox-app`: поддержка работы без консольного окна, перехват сигналов завершения (`ctrlc`, `SetConsoleCtrlHandler`, `panic::set_hook`).
- Веб-панель получает тумблер «Запуск вместе с Windows» на вкладке «Оборудование».
