# Design: Интерактивный редактор зон в Web UI

## Context

В веб-интерфейсе ReAmbiBox контейнер `.monitor-frame` (`#monitor-canvas`) отображает зоны экрана. Зоны имеют относительные координаты от 0.0 до 1.0 (`rect.x`, `rect.y`, `rect.width`, `rect.height`). Бэкенд уже поддерживает сохранение массива `zones` через `POST /api/config`.
См. `proposal.md` для мотивации.

## Goals / Non-Goals

**Goals:**
- Реализовать плавный Drag & Drop для зон внутри `.monitor-frame`.
- Реализовать масштабирование зоны за правый нижний маркер.
- Добавить визуальную привязку (Snapping) к границам экрана (0%, 100%).
- Добавить мини-панель свойств выбранной зоны (X%, Y%, W%, H%, номер диода) с возможностью тонкой подстройки.
- Обеспечить дебаунс отправки данных на сервер при перетаскивании и немедленное сохранение при отпускании мыши.

**Non-Goals:**
- Полная замена нативного оверлея (оверлей остаётся для калибровки поверх реальных окон и игр).
- Сложные трехмерные трансформации (зоны остаются двумерными прямоугольниками).

## Decisions

### 1. Архитектура взаимодействия с DOM
- **Решение**: Использовать `pointerdown`, `pointermove`, `pointerup` (с `setPointerCapture`) на элементе холста/зоны.
- **Обоснование**: `PointerEvents` надежно работают и с мышью, и с тач-экранами, и корректно захватывают курсор даже при выходе за пределы фрейма монитора во время быстрого движения.

### 2. Координатная система и привязка (Snapping)
- **Решение**: Все вычисления производятся в относительных координатах (0.0 .. 1.0) относительно `getBoundingClientRect()` родительского элемента `#monitor-canvas`. Порог привязки к границам — 0.015 (1.5%).
- **Обоснование**: Независимость от масштаба браузера, адаптивности и разрешения окна.

### 3. Синхронизация с сервером
- **Решение**: Во время движения мыши обновлять локальные зоны и UI; по событию `pointerup` отправлять финальный массив `zones` через `queueConfigUpdate({ zones })`.
- **Обоснование**: Исключает избыточный сетевой трафик и гарантирует мгновенный отклик интерфейса (60 FPS).

## Risks / Trade-offs

- [Конфликт периодического `fetchStatus` с активным перетаскиванием] → Если пользователь перетаскивает зону (`isDragging == true`), `fetchStatus` не должен перезаписывать `canvas.innerHTML`.
