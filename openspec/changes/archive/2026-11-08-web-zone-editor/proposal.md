# Proposal: Интерактивный Drag & Drop редактор зон в Web UI

## Why

В настоящее время детальное перемещение и изменение размеров зон возможно только через полноэкранный нативный оверлей Windows. В окне веб-интерфейса зоны отображаются только статично внутри макета монитора. Возможность перетаскивать и изменять размер зон прямо в браузере мышью существенно повышает удобство настройки, позволяет калибровать подсветку в компактном окне без перекрытия всего рабочего стола и обеспечивает мгновенный визуальный контроль параметров.

## What Changes

- Интерактивный Drag & Drop для зон экрана внутри контейнера монитора в Web UI (`#monitor-canvas`).
- Маркер изменения размера (Resize handle) в правом нижнем углу каждой зоны в Web UI.
- Мягкая привязка (Snapping) к краям экрана и соседним зонам для ровного выравнивания по периметру.
- Панель информации о выбранной зоне (номер, координаты X/Y в %, размеры W/H в %) с возможностью ручного ввода точных значений.
- Кнопка сохранения изменений зон в конфигурацию с мгновенным обновлением конвейера захвата.

- `ui/index.html`: панель параметров выделенной зоны и кнопки управления редактором.
- `ui/style.css`: стили для маркеров ресайза, активного состояния и перетаскивания.
- `ui/app.js`: обработчики мыши (`mousedown`, `mousemove`, `mouseup`) с расчетом координат в процентах и отправкой `POST /api/config`.
