# Spec Delta: zone-editor

## ADDED Requirements

### Requirement: Интерактивный редактор зон в Web UI
Система SHALL / ДОЛЖНА позволять пользователю интерактивно перемещать (Drag & Drop) и масштабировать зоны захвата экрана непосредственно внутри холста монитора в веб-интерфейсе с сохранением новых координат в конфигурации.

#### Scenario: Перетаскивание зоны мышью в Web UI
- **WHEN** пользователь зажимает зону мышью на холсте `#monitor-canvas` и перемещает курсор
- **THEN** зона плавно перемещается вслед за курсором в пределах границ виртуального экрана, а новые координаты отображаются в информационном блоке.

#### Scenario: Изменение размера зоны за угловой маркер в Web UI
- **WHEN** пользователь зажимает маркер ресайза в правом нижнем углу зоны и тянет его
- **THEN** ширина и высота зоны пропорционально изменяются, не выходя за пределы экрана.

#### Scenario: Привязка зоны к краям монитора (Snapping)
- **WHEN** координата зоны при перемещении оказывается ближе 2% к краю экрана (0% или 100%)
- **THEN** система мягко примагничивает зону к границе экрана для идеально ровного выравнивания.

#### Scenario: Сохранение отредактированных зон
- **WHEN** пользователь завершает перемещение или нажимает кнопку «Сохранить зоны»
- **THEN** обновленный массив зон отправляется на сервер через `POST /api/config`, персистентно сохраняется в `config.json` и сразу применяется к конвейеру захвата.
