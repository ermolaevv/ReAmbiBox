# Архитектурный дизайн: Сетевой вывод WLED (DDP / UDP)

## 1. Спецификация протокола DDP (Distributed Display Protocol)
Протокол DDP является современным открытым стандартом передачи пикселей по UDP.
Порт по умолчанию: **4048**.

### Структура заголовка DDP (10 байт):
| Байт | Поле | Описание | Значение по умолчанию |
|---|---|---|---|
| 0 | Flags | `0x40` (v1) \| `0x01` (Push) = `0x41` | `0x41` (отобразить сразу) |
| 1 | Sequence | Номер пакета (0–15 или 1–255) | Инкремент с переполнением |
| 2 | Data Type | Тип данных: `0x01` = RGB 24bpp | `0x01` |
| 3 | Destination | ID устройства: `0x01` = Default | `0x01` |
| 4..7 | Offset | Смещение первого пикселя в байтах (Big-Endian u32) | `0x00000000` |
| 8..9 | Length | Длина полезной нагрузки в байтах (Big-Endian u16, `N * 3`) | `len_hi`, `len_lo` |

Сразу после 10 байт заголовка следует `count * 3` байт данных в порядке RGB (или выбранном пользователем GRB/BRG и т.д.).

### Многопакетная фрагментация (при большом количестве диодов):
- Максимальный размер полезной нагрузки в одном UDP-пакете без фрагментации IP: 1440 байт (480 RGB диодов).
- Если количество диодов превышает 480, `WledDriver` разбивает данные на чанки по 480 диодов с соответствующим `offset` в байтах (`chunk_idx * 480 * 3`). Флаг `Push` (бит 0) устанавливается на последнем пакете кадра.

## 2. Спецификация протокола WARLS (WLED UDP realtime)
Порт по умолчанию: **21324**.
Формат пакета:
- Байт 0: `0x02` (протокол WARLS)
- Байт 1: Время удержания пакета (в секундах, например `1` или `2`)
- Далее для каждого диода: 4 байта `[led_index, R, G, B]`.

## 3. Архитектура драйвера `WledDriver`
```rust
pub struct WledDriver {
    host: String,
    port: u16,
    protocol: WledProtocol, // Ddp, Warls
    color_order: String,
    last_led_count: usize,
    sequence: u8,
    socket: Option<UdpSocket>,
}
```
Реализует `DeviceDriver`:
- `connect()`: привязывает локальный сокет `0.0.0.0:0`, настраивает `connect(target_addr)` для быстрого `send()`.
- `send_frame()`: формирует и отправляет DDP/WARLS датаграммы.
- `blank_leds()`: отправляет кадр из черных диодов.
- `emergency_blank(host, port, count)`: создает временный сокет и шлет пакет выключения.

## 4. Конфигурация `AppConfig`
- `output_type: String` ("serial" или "wled")
- `wled_host: String` (например "192.168.1.100")
- `wled_port: u16` (по умолчанию 4048)
- `wled_protocol: String` ("ddp" или "warls")

  - Переключатель: `[ USB Serial (Adalight) ]` / `[ Wi-Fi Сеть (WLED) ]`
  - При выборе "Wi-Fi Сеть (WLED)":
    - Поле ввода IP-адреса WLED
    - Поле ввода UDP порта (по умолчанию 4048)
    - Выбор протокола (DDP / WARLS)
    - Кнопка "Тест подключения (Ping / Blink)"
