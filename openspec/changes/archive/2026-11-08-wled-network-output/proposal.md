# Изменение: Поддержка сетевых протоколов WLED (DDP / UDP)

## 1. Проблема и мотивация
В настоящее время ReAmbiBox выводит данные подсветки исключительно через проводной последовательный порт USB (протокол Adalight). Однако огромное количество современных установок Ambilight и умного дома используют контроллеры ESP8266/ESP32 с прошивкой **WLED**, подключенные к локальной сети по Wi-Fi. Подключение ленты к ПК кабелем USB часто неудобно (монитор на кронштейне, телевизор на стене, удаленный системный блок).

Поддержка прямого сетевого вывода по протоколу WLED DDP (Distributed Display Protocol, UDP порт 4048) и WARLS (UDP порт 21324) решает эту проблему:
- Передача кадров подсветки в реальном времени с ультранизкой задержкой (< 2 мс в локальной сети).
- Отсутствие необходимости в физическом USB-кабеле и драйверах виртуальных COM-портов (CH340/CP2102).
- Полная совместимость с любой версией прошивки WLED.
- Поддержка произвольного количества диодов (включая автоматическое разбиение на пакеты при необходимости).

## 2. Предлагаемое решение
1. **Реализация `WledDriver`** в `reambibox-core::device::wled`:
   - Реализация интерфейса `DeviceDriver`.
   - Протокол **DDP** (Distributed Display Protocol, UDP порт 4048 по умолчанию): 10-байтный заголовок (`0x41`, seq, `0x01`, `0x01`, offset_32, len_16) + RGB полезная нагрузка.
   - Протокол **WARLS** (порт 21324) в качестве альтернативы: заголовок `[0x02, timeout]`, за которым следуют пары `[led_index, R, G, B]` или потоковый DRGB.
   - Поддержка `blank_leds()` и `emergency_blank(host, port, count)` через UDP-сокет с установленным таймаутом.
2. **Расширение конфигурации `AppConfig`**:
   - `output_type: String` ("serial" | "wled", по умолчанию "serial").
   - `wled_host: String` (по умолчанию "192.168.1.100").
   - `wled_port: u16` (по умолчанию 4048).
   - `wled_protocol: String` ("ddp" | "warls", по умолчанию "ddp").
3. **Унификация аппаратного потока вывода в `main.rs`**:
   - Поддержка динамического переключения между `AdalightDriver` и `WledDriver` на лету без перезапуска приложения при изменении конфигурации через Web UI.
   - Индикация статуса подключения сетевого устройства в трее и Web UI ("WLED (192.168.1.100:4048)").
4. **Интерфейс Web UI**:
   - На вкладке "Оборудование" переключатель типа вывода: "USB Serial (Adalight)" / "Wi-Fi Сеть (WLED)".
   - Интерактивные поля для ввода IP-адреса, порта, протокола.
   - Кнопка "Проверить связь" / "Тестовый кадр" для немедленной проверки связи с контроллером WLED.
