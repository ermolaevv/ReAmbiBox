# Design: english-localization

## Context

Приложение ReAmbiBox состоит из бэкенда на Rust (`reambibox-app`, `reambibox-core`), системного трея Windows (`tray.rs`) и одностраничного веб-интерфейса (`ui/index.html`, `ui/app.js`, `ui/style.css`). Для внедрения поддержки двух языков (RU и EN) требуется сквозная интеграция: хранение выбранного языка в конфигурации, динамический перевод DOM-элементов в браузере и поддержка локализованных строк контекстного меню в Win32 API трея.

## Goals / Non-Goals

**Goals:**
- Сохранение языка (`language: "ru" | "en"`) в `AppConfig` со значением по умолчанию `"ru"`.
- Легковесный механизм интернационализации (i18n) на стороне Web UI без внешних тяжелых библиотек: словарь переводов ключей (`ui/i18n.js` или объект в `app.js`) с функцией обновления текста элементов по `data-i18n` атрибутам и генерацией динамических строк.
- Переключатель языка (кнопки RU / EN) в шапке веб-интерфейса с мгновенным применением и синхронизацией с бэкендом.
- Подменю «Язык / Language» в трее Windows со сменой языка интерфейса и меню.

**Non-Goals:**
- Автоматический перевод пользовательских имен пресетов (имена пресетов, созданные пользователем, сохраняются в оригинальном виде).
- Поддержка десятков языков (на данном этапе фокусируемся на качественном русском и английском).

## Decisions

### 1. Архитектура i18n в веб-интерфейсе
- **Решение**: Добавить в HTML-разметку data-атрибуты `data-i18n="key"` для статичного текста и `data-i18n-title="key"` для всплывающих подсказок.
- **Словарь**: Создать структурированный объект `TRANSLATIONS = { ru: { ... }, en: { ... } }`, содержащий переводы всех заголовков, лейблов, ползунков, кнопок и динамических сообщений (например, статусы подключения, подтверждения удаления, модальные окна мастера).
- **Функция перевода**: `setLanguage(lang)`:
  - Обновляет атрибут `lang` у `<html>`.
  - Проходит по всем элементам с `[data-i18n]` и заменяет `textContent`.
  - Проходит по элементам с `[data-i18n-title]` / `[data-i18n-placeholder]`.
  - Обновляет активный класс на кнопках переключателя (`btn-lang-ru`, `btn-lang-en`).
  - Сохраняет выбор в `localStorage` и отправляет на сервер через `queueConfigUpdate({ language: lang })`.

### 2. Поддержка языка в `AppConfig`
- Добавить поле в `crates/reambibox-core/src/config/mod.rs`:
  ```rust
  #[serde(default = "default_language")]
  pub language: String,
  ```
- В `default_language()` возвращать `"ru".to_string()`.
- При вызове `GET /api/config` передавать `language` клиенту.

### 3. Локализация контекстного меню трея Windows
- Константы идентификаторов меню:
  ```rust
  const ID_MENU_LANG_RU: usize = 2101;
  const ID_MENU_LANG_EN: usize = 2102;
  ```
- Формирование пунктов меню на основе текущего `cfg.language`:
  - Если `"en"`:
    - "Control Panel"
    - "Turn Off / On"
    - "Presets"
    - "Brightness +10% / -10%"
    - "Zone Overlay"
    - "Language" -> [✓] English, [ ] Русский
    - "Exit"
  - Если `"ru"`:
    - аналогично на русском языке.

## Risks / Trade-offs

- **[Risk]** Динамически генерируемый контент (чипы пресетов, статусы FPS, сообщения мастера) может остаться на старом языке при смене.
  → *Mitigation*: Все функции рендеринга (`renderPresets`, `renderZones`, `fetchStatus`) используют функцию `t(key)` для получения актуальных строк.
