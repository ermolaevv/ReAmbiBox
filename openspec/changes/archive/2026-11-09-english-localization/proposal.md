# Proposal: english-localization

## Why

В настоящее время пользовательский веб-интерфейс, конфигурация и системный трей ReAmbiBox представлены исключительно на русском языке. Для расширения аудитории, удобства англоязычных пользователей и публикации проекта на международных платформах (GitHub, Reddit и др.) необходима полноценная поддержка английского языка (i18n / localization) с возможностью мгновенного переключения между RU и EN.

## What Changes

- **Модель конфигурации (`AppConfig`)**: добавлено поле `language: String` (по умолчанию `"ru"`, поддерживаемые значения: `"ru"`, `"en"`).
- **Веб-интерфейс (`ui`)**:
  - Добавлен компактный переключатель языка (RU / EN) в шапку веб-панели управления.
  - Реализован легковесный модуль интернационализации (словарь переводов `i18n` в `ui/app.js` или `ui/i18n.js`) для всех вкладок, карточек, ползунков, кнопок, подсказок, статусов, мастера калибровки и диалогов пресетов.
  - Мгновенное переключение языка интерфейса без перезагрузки страницы с сохранением выбора в `config.json` и `localStorage`.
- **Контекстное меню трея Windows (`crates/reambibox-app/src/tray.rs`)**:
  - Добавлено подменю «Язык / Language» (RU / EN) с отметкой текущего активного языка.
  - Тексты пунктов меню трея («Панель управления», «Включить/Выключить подсветку», «Пресеты», «Оверлей», «Выход») отображаются на выбранном языке.

## Capabilities

### New Capabilities
- `localization`: поддержка многоязычности (RU / EN) в пользовательском веб-интерфейсе, системном трее Windows и конфигурации приложения с сохранением пользовательского выбора.

## Impact

- `crates/reambibox-core/src/config/mod.rs`: добавление поля `language` в `AppConfig`.
- `crates/reambibox-app/src/tray.rs`: локализованные строки меню трея и подменю выбора языка.
- `crates/reambibox-app/src/main.rs`: передача `language` в API ответов и сохранение через `POST /api/config`.
- `ui/index.html`, `ui/app.js`, `ui/style.css`: разметка переключателя языка, словарь переводов и функция динамической локализации DOM.
