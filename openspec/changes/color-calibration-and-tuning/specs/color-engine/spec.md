# Spec Delta: color-calibration-and-tuning

## ADDED Requirements

### Requirement: Калибровка баланса белого (White Balance R/G/B Gain)
Система SHALL / ДОЛЖНА поддерживать индивидуальные множители усиления каналов красного, зелёного и синего (от 0.0 до 2.0 с шагом 0.01) для точной компенсации цвета поверхности проецирования подсветки.

#### Scenario: Применение калибровочных коэффициентов R/G/B
- **WHEN** пользователь изменяет коэффициенты баланса белого (например, Red=0.9, Green=1.0, Blue=1.1)
- **THEN** выходные значения цветовых каналов пропорционально масштабируются и ограничиваются диапазоном [0, 255] без появления цветовых артефактов.

#### Scenario: Комбинированная обработка через таблицу LUT
- **WHEN** пересчитывается предрассчитанная таблица гаммы `GammaLut`
- **THEN** коэффициенты усиления R/G/B интегрируются непосредственно в предрассчитанные массивы каждого канала, сохраняя время выборки O(1) без математических операций с плавающей точкой в цикле рендеринга.

### Requirement: Порог отсечки чёрного (Black Level Threshold)
Система SHALL / ДОЛЖНА поддерживать настраиваемый порог отсечки чёрного (0–50), ниже которого светодиоды зоны полностью гасятся в значение (0, 0, 0).

#### Scenario: Гашение подсветки в тёмных сценах
- **WHEN** максимальная или средняя яркость зоны кадра падает ниже установленного порога отсечки
- **THEN** итоговый цвет зоны устанавливается в [0, 0, 0], полностью отключая свечение ленты на черных сценах.

#### Scenario: Сохранение цвета выше порога
- **WHEN** яркость зоны превышает порог отсечки
- **THEN** цвет передается в конвейер вывода без ступенчатых разрывов яркости.

### Requirement: Коррекция насыщенности цвета (Saturation Adjustment)
Система SHALL / ДОЛЖНА обеспечивать регулировку цветовой насыщенности (0.0–2.0, по умолчанию 1.0) без сдвига цветового тона (Hue).

#### Scenario: Усиление насыщенности
- **WHEN** пользователь задает коэффициент насыщенности более 1.0 (например, 1.25)
- **THEN** цветовая разность пикселей относительно монохромной яркости Luma увеличивается, делая цвета более сочными.

#### Scenario: Обесцвечивание при нулевой насыщенности
- **WHEN** задается коэффициент насыщенности 0.0
- **THEN** зоны преобразуются в оттенки серого, сохраняя точную монохромную яркость.
