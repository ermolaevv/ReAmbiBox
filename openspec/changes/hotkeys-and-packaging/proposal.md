# Proposal: Глобальные горячие клавиши и упаковка дистрибутива

## Why

Управление подсветкой через веб-браузер удобно для детальной настройки, однако в повседневном использовании (во время игр, просмотра фильмов или работы) открывать браузер для включения/выключения подсветки или изменения яркости неудобно. Пользователю необходим мгновенный доступ через глобальные сочетания клавиш Windows в любой момент времени.
Кроме того, для удобства использования ReAmbiBox должен запускаться в систему автоматически в полностью тихом фоновом режиме (свернутым в трей без открытия лишних окон) и поставляться в виде готового к установке и переносу дистрибутива.

## What Changes

1. **Глобальные горячие клавиши Windows (Global Hotkeys)**:
   - Фоновая регистрация системных хоткеев через Win32 API (`RegisterHotKeyW` / `WM_HOTKEY`):
     - `Ctrl+Shift+A`: Мгновенное включение/выключение подсветки (Toggle Power).
     - `Ctrl+Shift+Up`: Увеличение общей яркости на +10%.
     - `Ctrl+Shift+Down`: Уменьшение общей яркости на -10%.
     - `Ctrl+Shift+O`: Мгновенный вызов/скрытие экранного оверлея зон калибровки.
   - Возможность включения/выключения хоткеев в настройках конфигурации.
2. **Тихий фоновый запуск в системный трей (Silent / Minimized Autostart)**:
   - Поддержка флага командной строки `--minimized` (или `--silent`), при котором приложение не выводит консоль и не открывает веб-интерфейс, а сразу начинает фоновую работу и размещает значок в системном трее Windows.
   - Обновление модуля автозагрузки в реестре Windows (`HKCU\...\Run`), чтобы при включении автозапуска записывалась команда с флагом `--minimized`.
3. **Упаковка дистрибутива (Packaging & Distribution)**:
   - Скрипт сборки автономного портативного релиза (`package.ps1` / ZIP-архив) со всеми статическими ресурсами (UI, иконка, манифест).
   - Скрипт/конфигурация создания полноценного установщика Windows (Inno Setup Script `.iss`) для установки в `Program Files` или `%LOCALAPPDATA%`, создания ярлыков в меню «Пуск» и деинсталлятора.

## Capabilities

### New Capabilities
- `global-hotkeys`: Системные горячие клавиши Windows для оперативного управления подсветкой, яркостью и оверлеем без перехода в браузер.
- `distribution`: Скрипты и манифесты сборки портативного релиза и Windows-инсталлятора (Inno Setup) для удобной установки и распространения.

### Modified Capabilities
- `autostart`: Поддержка тихого фонового запуска при старте системы с ключом `--minimized`.

## Impact

- Добавление модуля `hotkeys.rs` в `reambibox-app` с интеграцией в событийный цикл Windows.
- Расширение `crates/reambibox-app/src/autostart.rs` для поддержки аргумента `--minimized`.
- Обновление парсинга аргументов командной строки в `main.rs`.
- Создание сборочных скриптов в каталоге `dist/`.
