# Spec Delta: Упаковка и дистрибуция

## Purpose

Предоставляет набор средств сборки и конфигураций для распространения приложения в виде портативного архива и полноценного инсталлятора Windows с поддержкой тихого фонового запуска.

## ADDED Requirements

### Requirement: Сборка портативного релиза и инсталлятора Windows
Система SHALL / ДОЛЖНА содержать сценарии для подготовки готового к распространению дистрибутива приложения.

#### Scenario: Подготовка портативного архива
- **WHEN** запускается сборочный скрипт `scripts/package.ps1`
- **THEN** выполняется сборка релизного бинарника, собираются все статические ресурсы (Web UI, манифест, иконки), и создается ZIP-архив `ReAmbiBox-Portable-vX.Y.Z.zip`.

#### Scenario: Сборка установщика Inno Setup
- **WHEN** компилируется установочный скрипт `scripts/installer.iss`
- **THEN** генерируется автономный исполняемый установщик `ReAmbiBox-Setup.exe`, который копирует файлы в целевой каталог, создает ярлыки в меню «Пуск» и регистрирует деинсталлятор.
