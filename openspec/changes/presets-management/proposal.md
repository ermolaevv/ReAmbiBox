# Proposal: presets-management

## Why
Пользователи используют подсветку в совершенно разных сценариях: просмотр кино в темноте требует высокой гаммы, сглаживания и детекции полос 21:9; соревновательные игры требуют максимальной частоты кадров, пониженного сглаживания и ярких насыщенных цветов; вечернее чтение или работа за компьютером требуют мягкого нейтрального статичного света; прослушивание музыки требует светомузыки. Ручная перенастройка десятка ползунков каждый раз неудобна. Требуется система профилей (пресетов) с возможностью быстрого переключения в 1 клик или по горячим клавишам.

## What Changes
- **Модель пресета (`Preset`)**: структура, хранящая профильные параметры подсветки (режим, яркость, сглаживание, гамма, насыщенность, баланс белого R/G/B, порог черного, letterbox, target_fps, аудио-эффект, чувствительность, статический цвет, опциональный хоткей).
- **Встроенные заводские пресеты (Default Presets)**: готовые предустановки «Кино», «Игры», «Чтение / Фоновый свет», «Музыка».
- **Управление пресетами**: возможность сохранять текущие настройки как новый пресет, перезаписывать существующий, удалять пользовательские пресеты и переименовывать их.
- **Быстрое переключение**:
  - В панели управления WebUI: переключатель пресетов и всплывающее меню управления.
  - В контекстном меню системного трея Windows: подменю «Пресеты» со списком и отметкой активного.
  - Поддержка горячих клавиш Windows для моментальной активации любимых пресетов.
- **REST API эндпоинты**:
  - `POST /api/presets/apply` — применение пресета по имени.
  - `POST /api/presets/save` — сохранение текущих настроек в пресет.
  - `POST /api/presets/delete` — удаление пользовательского пресета.

## Capabilities

### New Capabilities
- `presets`: хранение, переключение, создание и удаление именованных профилей конфигурации подсветки.

## Impact
- `crates/reambibox-core/src/config/mod.rs`: добавление структуры `Preset` и поля `presets: Vec<Preset>`, `active_preset: Option<String>` в `AppConfig`.
- `crates/reambibox-app/src/main.rs`: реализация API маршрутов `/api/presets/*` и синхронизация активного пресета с конвейером.
- `crates/reambibox-app/src/tray.rs`: добавление подменю пресетов в контекстное меню трея.
- `ui/index.html`, `ui/app.js`, `ui/style.css`: селектор пресетов, модальное окно управления пресетами и быстрое переключение.
