# Proposal: Создание ReAmbiBox — современной реализации AmbiBox

## Why

Оригинальное приложение AmbiBox (последнее обновление — версия 2.1.7 от 2015 года для Windows 7) заброшено и не поддерживается. На современных системах (Windows 10/11) его устаревшие методы захвата экрана (GDI/DirectDraw) вызывают критическую нагрузку на процессор, показывают чёрный экран в играх и приложениях с аппаратным ускорением/DRM, а 32-битный устаревший интерфейс не поддерживает экраны высокого разрешения (DPI) и современные стандарты подсветки.

ReAmbiBox призван заменить устаревший AmbiBox, предоставив аппаратный захват экрана на GPU (60–120+ FPS без нагрузки на CPU), поддержку современных и легаси устройств светодиодной подсветки (начиная с Adalight на COM10), высокую энергоэффективность и современный визуальный интерфейс настройки.

## What Changes

- **Реализация нативного ядра (Rust)**: захват рабочего стола через Windows DXGI Desktop Duplication API (Direct3D 11) с нулевым копированием через CPU.
- **Движок обработки цвета (SIMD & Temporal Smoothing)**: быстрый расчёт средних значений RGB по полигональным/прямоугольным зонам и сглаживание переходов цветов.
- **Модульная система драйверов вывода**:
  - Первоочередная поддержка контроллеров **Adalight** (протокол `Ada` + счетчик + payload) на порту COM10 (115200 бод).
  - Архитектурная поддержка легаси-протоколов (AtmoLight, SEDU, Paintpack HID) и современных сетевых протоколов (WLED UDP/DDP).
- **Сервер обратной совместимости Lightpack API**: реализация стандартного текстового TCP-сокета на порту 3636 для поддержки существующих плагинов (Kodi/XBMC, мобильные пульты, скрипты автоматизации).
- **Современный пользовательский интерфейс (Tauri 2.0)**:
  - Интерактивный полупрозрачный полноэкранный редактор зон подсветки (Drag-and-Drop, сетки, привязка к граням монитора).
  - Панель настроек (выбор COM-порта, цветовая калибровка, гамма, баланс белого, задержка).
  - Работа в системном трее Windows с автозапуском.
- **Исключение устаревших компонентов**: отказ от встроенного ИК-сервера (IR receiver), эмуляции клавиатуры/мыши и WinLIRC с фокусом исключительно на Ambilight-подсветке.

## Capabilities

### New Capabilities
- `screen-capture`: Аппаратный захват кадров рабочего стола в реальном времени через Windows DXGI Desktop Duplication API (D3D11) с поддержкой мультимониторных конфигураций и минимальной задержкой.
- `color-engine`: Математический расчёт усредненных цветов по настраиваемым зонам экрана, компенсация черных полос (letterbox/pillarbox) и экспоненциальное временное сглаживание (temporal smoothing).
- `device-output`: Абстракция устройств вывода светодиодных данных и реализация протокола Adalight (COM-порт 115200 бод) с защитой от переполнения буфера и восстановлением при обрыве соединения.
- `compatibility-api`: Текстовый TCP-сервер протокола Lightpack (порт 3636) для управления профилями, статусом и отдельными светодиодами из сторонних приложений.
- `zone-editor`: Интерактивный графический интерфейс настройки геометрии и параметров зон захвата прямо поверх рабочего стола.

## Impact

- **Платформа**: Windows 10/11 x64.
- **Аппаратные интерфейсы**: доступ к COM-портам (включая COM10) через Win32 Overlapped I/O, доступ к видеопамяти через DirectX 11.
- **Сетевые интерфейсы**: локальный TCP-порт 3636.
- **Внешние зависимости**: Rust toolchain, Tauri 2.0, WebView2 Runtime (встроен в Windows 10/11).
