# Proposal: Интеграция с рабочим столом Windows, системный трей и управление питанием

## Why

Сейчас ReAmbiBox работает как консольное приложение с открытым окном терминала. Для постоянного и комфортного повседневного использования программа должна функционировать как нативное фоновое приложение Windows: находиться в системном трее (Notification Area), управляться через контекстное меню, запускаться автоматически при старте системы и автоматически отключать подсветку при блокировке экрана (`Win + L`) или переходе монитора в спящий режим.

## What Changes

- Добавлена интеграция с системным треем Windows (иконка в области уведомлений с цветным статусом активности).
- Реализовано контекстное меню трея: включение/выключение подсветки, выбор режима, открытие веб-панели управления, включение/выключение автозапуска, выход из приложения.
- Реализовано бесшовное скрытие консольного окна в релизной сборке (`#![windows_subsystem = "windows"]`) с возможностью запуска в режиме отладки через флаг `--console`.
- Реализовано управление автозапуском через реестр Windows (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
- Реализована обработка системных событий Windows (`WM_POWERBROADCAST`, `WTSRegisterSessionNotification`): автоматическое выключение светодиодов при выключении монитора или блокировке ПК и мгновенное возобновление при пробуждении.

## Capabilities

### New Capabilities
- `system-tray`: Фоновая работа в системном трее Windows с контекстным меню и индикацией статуса.
- `autostart`: Управление автозагрузкой приложения вместе с Windows через реестр.
- `power-management`: Отслеживание блокировки сессии и спящего режима монитора для автоматического тушения и пробуждения светодиодной ленты.

### Modified Capabilities
- `device-output`: Добавлен перевод устройства в энергосберегающий режим (отправка чёрного кадра и приостановка таймера отправки) при событиях сна/блокировки.

## Impact

- Добавляются зависимости Windows API (`windows-rs` фичи `Win32_UI_WindowsAndMessaging`, `Win32_System_Power`, `Win32_System_RemoteDesktop`, `tray-icon` / нативный Win32 Message Loop).
- Обновляется `reambibox-app`: поддержка работы без консольного окна и интеграция с системным циклом сообщений Windows.
- Веб-панель получает тумблер «Запуск вместе с Windows» на вкладке «Оборудование».
