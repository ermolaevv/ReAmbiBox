# Spec Delta: power-management

## Purpose

Автоматически отслеживает события энергосбережения дисплея и блокировки пользовательской сессии Windows, выключая подсветку для экономии ресурса светодиодов и электроэнергии.

## ADDED Requirements

### Requirement: Мониторинг спящего режима монитора и блокировки сессии
Система SHALL / ДОЛЖНА подписаться на системные уведомления Windows об отключении дисплея и блокировке экрана (`Win + L`).

#### Scenario: Переход монитора в режим сна или отключение питания
- **WHEN** операционная система отправляет сообщение `WM_POWERBROADCAST` с параметром `PBT_POWERSETTINGCHANGE` (отключение дисплея)
- **THEN** конвейер захвата экрана приостанавливается, а на светодиодную ленту немедленно отправляется чёрный кадр.

#### Scenario: Блокировка рабочей станции Windows
- **WHEN** пользователь блокирует компьютер клавишами `Win + L` (`WTS_SESSION_LOCK`)
- **THEN** светодиодная лента плавно гаснет до возврата пользователя в систему.

#### Scenario: Пробуждение монитора или разблокировка сессии
- **WHEN** дисплей снова включается (`GUID_MONITOR_POWER_ON`) или сессия разблокируется (`WTS_SESSION_UNLOCK`)
- **THEN** захват экрана возобновляется, и подсветка восстанавливает нормальную работу.
