# Tasks: Интеграция с рабочим столом Windows, системный трей и управление питанием

## 1. Конфигурация подсистемы Windows и консоли

- [ ] 1.1 Добавить в `reambibox-app` директиву `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]` и разбор аргумента `--console` с вызовом `AttachConsole` / `AllocConsole` для вывода логов при необходимости отладки. Проверить запуск с флагом и без него.
- [ ] 1.2 Подключить необходимые модули Windows API (`Win32_UI_Shell`, `Win32_UI_WindowsAndMessaging`, `Win32_System_Power`, `Win32_System_RemoteDesktop`) в `Cargo.toml`. Проверить компиляцию проекта.

## 2. Системный трей и контекстное меню

- [ ] 2.1 Создать модуль `tray.rs` в `reambibox-app` с регистрацией иконки приложения в области уведомлений Windows (`Shell_NotifyIconW`). Проверить появление иконки в трее.
- [ ] 2.2 Реализовать реакцию на одинарный и двойной клик левой кнопкой мыши по иконке трея с открытием страницы `http://localhost:3637` в системном веб-браузере по умолчанию.
- [ ] 2.3 Реализовать контекстное меню правой кнопки мыши (пункты «Включить/Выключить подсветку», «Открыть панель управления», «Автозагрузка с Windows», «Выход») и связать команды с общим состоянием приложения. Проверить работу всех пунктов меню.

## 3. Управление автозапуском через реестр Windows

- [ ] 3.1 Реализовать модуль `autostart.rs` для работы с веткой реестра `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`: методы проверки статуса автозапуска, добавления текущего `current_exe()` и удаления ключа.
- [ ] 3.2 Добавить поле `autostart` в структуры API (`ApiStatusResponse` и `ConfigUpdate`), поддержать чтение и запись через `GET /api/config` и `POST /api/config`.
- [ ] 3.3 Добавить переключатель «Запуск вместе с Windows» на вкладку «Оборудование» в веб-интерфейсе `ui/index.html` и связать его с API в `ui/app.js`. Проверить сохранение и удаление ключа в реестре через PowerShell.

## 4. Мониторинг спящего режима монитора и блокировки сессии

- [ ] 4.1 Создать скрытое окно сообщений Win32 для подписки на события питания через `RegisterPowerSettingNotification` (`GUID_MONITOR_POWER_ON`) и блокировки сессии через `WTSRegisterSessionNotification`.
- [ ] 4.2 Реализовать автоматическое гашение ленты (отправка чёрного кадра и временная приостановка таймера отправки) при отключении экрана или блокировке ПК (`Win + L`).
- [ ] 4.3 Реализовать автоматическое возобновление захвата и подсветки при включении экрана или разблокировке сессии. Проверить реакцию на имитацию событий сна и пробуждения.

## 5. Сквозная проверка и верификация

- [ ] 5.1 Собрать релизную версию `cargo build --release` и запустить exe: убедиться в отсутствии консольного окна, наличии иконки в трее и корректной работе веб-панели управления.
- [ ] 5.2 Заблокировать рабочую станцию (`Win + L`) и убедиться, что светодиоды выключаются, а при входе в систему подсветка мгновенно восстанавливается.
