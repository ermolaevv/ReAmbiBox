# Proposal: Нативный экранный оверлей зон захвата и интерактивный мастер калибровки

## Why

В старом AmbiBox 2.1.7 ключевой и самой удобной функцией была визуальная калибровка зон: программа создавала полупрозрачные пронумерованные прямоугольные окна поверх всех запущенных приложений прямо по периметру монитора, позволяя пользователю идеально сопоставить экранные зоны с реальным физическим расположением светодиодов за экраном. 

В ReAmbiBox зоны уже настроены в конфигурационном файле, однако пользователю необходим наглядный инструмент прямой настройки: возможность включить отображение этих зон прямо на рабочем столе («Show areas of capture»), свободно перетаскивать и изменять их размеры мышью, а также быстро расставлять их умным мастером периметра (Top / Bottom / Left / Right / Start Corner / Direction).

## What Changes

1. **Нативный экранный оверлей Windows (`zone_overlay.rs`)**:
   - Реализация полупрозрачных поверхностных окон (`WS_EX_TOPMOST | WS_EX_LAYERED | WS_EX_TOOLWINDOW`), отображающихся поверх любых игр и приложений Windows на выбранном мониторе.
   - Отрисовка номера каждой зоны (1..N) крупным шрифтом и полупрозрачной цветной рамки (как в AmbiBox).
   - Интерактивный Drag & Drop: перетаскивание зоны левой кнопкой мыши прямо по экрану и изменение размера.
   - Горячая клавиша / кнопка управления «Показать / Скрыть зоны захвата».

2. **Интерактивный мастер расстановки зон (Zone Perimeter Wizard)**:
   - Полноценный интерфейс мастера на вкладке «Редактор зон» в Web UI:
     - Задание количества LED: Сверху, Снизу, Слева, Справа (для текущих 98 LED: 30 / 30 / 19 / 19).
     - Выбор начальной точки (Bottom-Left, Bottom-Right, Top-Left, Top-Right).
     - Выбор направления обхода (По часовой стрелке / Против часовой стрелки).
     - Настройка глубины и отступов захвата в процентах.
     - Кнопка «Сгенерировать и применить к экрану».

3. **Синхронизация с REST API и движком захвата в реальном времени**:
   - Команды `POST /api/overlay/toggle`, `GET /api/overlay/status`.
   - Мгновенное обновление координат зон в разделяемой памяти: поток DXGI немедленно начинает сэмплировать цвета из обновленных координат без перезапуска сервиса.
   - Автоматическое сохранение изменений в `config.json`.

## Capabilities

### Modified Capabilities
- `zone-editor`: расширение требований для поддержки нативного интерактивного экранного оверлея поверх всех окон с перемещением зон мышью (Drag & Drop) и расширенного мастера распределения периметра.

## Impact
- **Модули**: `reambibox-app` (модуль оверлея Win32 GDI/DirectComposition/Layered Windows, связка с треем и Web UI), `reambibox-core` (расширение `ZoneWizard`).
- **Интерфейс**: добавление кнопок «Показать зоны на экране» в трей и в Web UI, модальное окно интерактивного мастера расстановки зон.
- **Производительность**: в режиме обычной работы оверлей полностью скрыт и не потребляет ресурсов GPU/CPU.
