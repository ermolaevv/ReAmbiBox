# color-engine Specification

## Purpose
Выполняет расчёт средних значений цвета RGB по заданным полигональным и прямоугольным зонам экрана, компенсирует черные полосы и сглаживает переходы во времени.

## Requirements

### Requirement: Расчёт среднего цвета по зонам
Система SHALL / ДОЛЖНА для каждой заданной зоны экрана вычислять усреднённый цвет (R, G, B) на основе пикселей захваченного кадра с использованием прореживания шага выборки (downsampling) для оптимизации нагрузки.

#### Scenario: Расчёт цвета зоны
- **WHEN** поступает новый захваченный кадр экрана
- **THEN** система вычисляет значение [R, G, B] для каждой активной зоны с погрешностью менее 1% и передаёт результирующий массив дальше по конвейеру.

### Requirement: Временное сглаживание цветов (Temporal Smoothing)
Система SHALL / ДОЛЖНА применять экспоненциальное или адаптивное сглаживание к значениям цветов зон во времени с использованием in-place буферизации (без промежуточных динамических аллокаций памяти) и аппаратной/LUT-коррекции гаммы и яркости.

#### Scenario: Плавное изменение цвета
- **WHEN** на экране происходит мгновенная смена сцены (с чёрного на белый)
- **THEN** итоговый цвет зоны плавно нарастает в течение настроенного периода времени (smoothing factor).

#### Scenario: Применение гамма-коррекции через предрассчитанную таблицу LUT
- **WHEN** вычисляются скорректированные по яркости и гамме цвета светодиодов
- **THEN** значения преобразуются через 256-байтную таблицу LUT за константное время O(1) без трансцендентных вызовов `powf` на каждом диоде.

#### Scenario: Нулевое выделение памяти при сглаживании (Zero-Allocation Smoothing)
- **WHEN** вызывается метод `smooth_into`
- **THEN** цвета сглаживаются и записываются непосредственно в переданный буфер без выделения новых векторов `Vec<RgbColor>`.

### Requirement: Детекция чёрных полос (Letterbox Detection)
Система SHALL / ДОЛЖНА автоматически определять наличие черных полос сверху/снизу (формат 21:9 на экране 16:9) или по бокам и смещать границы эффективного захвата для краевых зон.

#### Scenario: Обнаружение фильмов с полосами
- **WHEN** воспроизводится фильм с чёрными полосами сверху и снизу более 2 секунд
- **THEN** краевые зоны автоматически берут цвет с границы реального видеопотока, а не с чёрных полос.

### Requirement: Калибровка баланса белого (White Balance R/G/B Gain)
Система SHALL / ДОЛЖНА поддерживать индивидуальные множители усиления каналов красного, зелёного и синего (от 0.0 до 2.0 с шагом 0.01) для точной компенсации цвета поверхности проецирования подсветки.

#### Scenario: Применение калибровочных коэффициентов R/G/B
- **WHEN** пользователь изменяет коэффициенты баланса белого (например, Red=0.9, Green=1.0, Blue=1.1)
- **THEN** выходные значения цветовых каналов пропорционально масштабируются и ограничиваются диапазоном [0, 255] без появления цветовых артефактов.

#### Scenario: Комбинированная обработка через таблицу LUT
- **WHEN** пересчитывается предрассчитанная таблица гаммы `GammaLut`
- **THEN** коэффициенты усиления R/G/B интегрируются непосредственно в предрассчитанные массивы каждого канала, сохраняя время выборки O(1) без математических операций с плавающей точкой в цикле рендеринга.

### Requirement: Порог отсечки чёрного (Black Level Threshold)
Система SHALL / ДОЛЖНА поддерживать настраиваемый порог отсечки чёрного (0–50), ниже которого светодиоды зоны полностью гасятся в значение (0, 0, 0).

#### Scenario: Гашение подсветки в тёмных сценах
- **WHEN** максимальная или средняя яркость зоны кадра падает ниже установленного порога отсечки
- **THEN** итоговый цвет зоны устанавливается в [0, 0, 0], полностью отключая свечение ленты на черных сценах.

#### Scenario: Сохранение цвета выше порога
- **WHEN** яркость зоны превышает порог отсечки
- **THEN** цвет передается в конвейер вывода без ступенчатых разрывов яркости.

### Requirement: Коррекция насыщенности цвета (Saturation Adjustment)
Система SHALL / ДОЛЖНА обеспечивать регулировку цветовой насыщенности (0.0–2.0, по умолчанию 1.0) без сдвига цветового тона (Hue).

#### Scenario: Усиление насыщенности
- **WHEN** пользователь задает коэффициент насыщенности более 1.0 (например, 1.25)
- **THEN** цветовая разность пикселей относительно монохромной яркости Luma увеличивается, делая цвета более сочными.

#### Scenario: Обесцвечивание при нулевой насыщенности
- **WHEN** задается коэффициент насыщенности 0.0
- **THEN** зоны преобразуются в оттенки серого, сохраняя точную монохромную яркость.
