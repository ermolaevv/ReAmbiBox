# compatibility-api Specification

## Purpose
Предоставляет совместимый со сторонними клиентами и оригинальным AmbiBox сетевой TCP-сервер по спецификации Lightpack API (порт 3636).

## Requirements

### Requirement: Обработка команд Lightpack API через сокет
Система SHALL / ДОЛЖНА прослушивать локальный TCP-порт 3636 и обрабатывать стандартные текстовые команды управления подсветкой, совместимые с протоколом Lightpack/AmbiBox.

#### Scenario: Запрос списка профилей
- **WHEN** клиент отправляет строку "getprofiles\n" в сокет
- **THEN** сервер отвечает строкой формата "profiles:<p1>;<p2>;...\n" со списком доступных профилей.

#### Scenario: Включение и выключение подсветки по API
- **WHEN** клиент отправляет команду "setstatus:on\n" или "setstatus:off\n"
- **THEN** система активирует или переводит подсветку в режим ожидания и возвращает подтверждение "ok\n".

#### Scenario: Установка цвета конкретных светодиодов
- **WHEN** клиент передает команду "setcolor:0-255,0,0;1-0,255,0\n"
- **THEN** система обновляет цвета указанных зон и отправляет их на активное устройство вывода.
