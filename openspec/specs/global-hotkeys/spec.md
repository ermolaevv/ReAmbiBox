# global-hotkeys Specification

## Purpose
Предоставляет пользователю возможность оперативного управления питанием подсветки, регулировкой яркости и отображением экранного оверлея зон с помощью глобальных клавиатурных сочетаний Windows.

## Requirements

### Requirement: Регистрация и перехват глобальных горячих клавиш Windows
Система SHALL / ДОЛЖНА регистрировать настраиваемые глобальные горячие клавиши в Windows и реагировать на их нажатие независимо от того, какое окно или игра активны, а также поддерживать их изменение и выборочное отключение отдельных комбинаций в реальном времени.

#### Scenario: Переключение питания подсветки по горячей клавише
- **WHEN** пользователь нажимает назначенную клавиатурную комбинацию питания (по умолчанию `Ctrl+Shift+A` или настроенную)
- **THEN** статус активности подсветки переключается (ВКЛ / ВЫКЛ), светодиоды мгновенно зажигаются или гаснут, а статус обновляется в общем состоянии приложения.

#### Scenario: Быстрое увеличение яркости
- **WHEN** пользователь нажимает назначенную комбинацию увеличения яркости (по умолчанию `Ctrl+Shift+Up` или настроенную)
- **THEN** уровень яркости подсветки увеличивается на 10% (с ограничением максимума в 100%), сохраняется в конфигурации и применяется к контроллеру.

#### Scenario: Быстрое уменьшение яркости
- **WHEN** пользователь нажимает назначенную комбинацию уменьшения яркости (по умолчанию `Ctrl+Shift+Down` или настроенную)
- **THEN** уровень яркости подсветки уменьшается на 10% (с ограничением минимума в 0%), сохраняется в конфигурации и применяется к контроллеру.

#### Scenario: Вызов экранного оверлея зон
- **WHEN** пользователь нажимает назначенную комбинацию оверлея (по умолчанию `Ctrl+Shift+O` или настроенную)
- **THEN** на экране мгновенно отображается или скрывается прозрачный оверлей калибровки зон захвата.

#### Scenario: Динамическое изменение комбинаций клавиш через Web UI
- **WHEN** пользователь изменяет комбинацию клавиш в панели управления Web UI и сохраняет настройки
- **THEN** система динамически снимает старую регистрацию клавиш в Windows (`UnregisterHotKey`), регистрирует новые комбинации (`RegisterHotKey`) и сохраняет их в `config.json` без перезапуска программы.

#### Scenario: Отключение отдельной горячей клавиши
- **WHEN** пользователь очищает клавиатурную комбинацию для конкретного действия в Web UI (нажатием кнопки «✕», клавиш Backspace/Delete или сохранением пустого значения)
- **THEN** система дерегистрирует соответствующую комбинацию в Windows (`UnregisterHotKey`), не перехватывает её, а в конфигурации сохраняется признак отсутствия клавиши.
