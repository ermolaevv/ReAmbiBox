# localization Specification

## Purpose
Обеспечивает полноценную поддержку русского и английского языков в пользовательском интерфейсе ReAmbiBox, контекстном меню системного трея Windows и конфигурационном файле с возможностью бесшовного переключения.

## Requirements

### Requirement: Поддержка выбора языка в конфигурации приложения
Система SHALL / ДОЛЖНА поддерживать сохранение и чтение параметра языка `language` в `AppConfig` (`"ru"` или `"en"`). По умолчанию используется русский язык (`"ru"`).

#### Scenario: Чтение и сохранение языка
- **WHEN** пользователь изменяет язык через интерфейс или API (`POST /api/config` с полем `language`)
- **THEN** значение сохраняется в `config.json`, обновляет активную конфигурацию и передается в ответах `GET /api/config`.

### Requirement: Локализация веб-панели управления
Веб-интерфейс SHALL / ДОЛЖЕН предоставлять переключатель языка (RU / EN) в шапке панели и динамически переводить все элементы интерфейса (навигацию, заголовки, ползунки, кнопки, подсказки, мастер зон, пресеты) без перезагрузки страницы.

#### Scenario: Переключение языка на английский
- **WHEN** пользователь нажимает кнопку переключения языка «EN» в веб-интерфейсе
- **THEN** все текстовые надписи интерфейса немедленно переводятся на английский язык, а выбор сохраняется в конфигурацию и `localStorage`.

#### Scenario: Переключение языка на русский
- **WHEN** пользователь нажимает кнопку «RU» в веб-интерфейсе
- **THEN** все текстовые надписи интерфейса немедленно переводятся на русский язык, а выбор сохраняется в конфигурацию и `localStorage`.

### Requirement: Локализация контекстного меню трея Windows
Контекстное меню системного трея Windows SHALL / ДОЛЖНО содержать подменю выбора языка («Язык / Language») и отображать пункты меню на выбранном языке.

#### Scenario: Отображение меню трея на английском языке
- **GIVEN** в конфигурации установлен язык `"en"`
- **WHEN** пользователь открывает контекстное меню трея Windows
- **THEN** пункты меню отображаются на английском языке («Control Panel», «Turn Off / On», «Presets», «Zone Overlay», «Exit»), а в подменю «Language» пункт «English» отмечен галочкой.
