# presets Specification

## Purpose
Обеспечивает сохранение, управление и моментальное переключение созданных пользователем наборов параметров подсветки (профилей) в 1 клик через веб-интерфейс или системный трей.

## Requirements

### Requirement: Хранение и структура пресетов
Система SHALL / ДОЛЖНА поддерживать сохранение пользовательских именованных пресетов, содержащих параметры режима работы, яркости, гаммы, сглаживания, насыщенности, баланса белого, отсечки черного, частоты кадров и аудио-эффектов. Список пресетов по умолчанию пуст и наполняется пользователем.

#### Scenario: Применение выбранного пресета
- **WHEN** пользователь активирует сохраненный пресет (через WebUI или контекстное меню трея)
- **THEN** все параметры отображения подсветки атомарно обновляются и применяются к конвейеру захвата и вывода без перезапуска приложения.

#### Scenario: Инициализация без предустановленных пресетов
- **WHEN** приложение запускается с чистой конфигурацией
- **THEN** список пресетов пуст, а текущие параметры берутся из базового конфига.

### Requirement: Создание, обновление и удаление пользовательских пресетов
Система SHALL / ДОЛЖНА позволять пользователю сохранять текущее состояние в новый пресет, обновлять существующий пресет и удалять любые ранее созданные пресеты.

#### Scenario: Создание нового пресета
- **WHEN** пользователь указывает имя и отправляет запрос на сохранение пресета
- **THEN** новый профиль сохраняется в конфигурационный файл `config.json` и становится доступным для выбора.

#### Scenario: Удаление пользовательского пресета
- **WHEN** пользователь запрашивает удаление пресета
- **THEN** пресет удаляется из списка, а конфигурационный файл обновляется.

### Requirement: Переключение пресетов через контекстное меню трея
Система SHALL / ДОЛЖНА отображать подменю «Пресеты» в контекстном меню системного трея Windows со списком сохраненных пользователем пресетов и отметкой текущего активного пресета.

#### Scenario: Выбор пресета из трея Windows
- **WHEN** пользователь нажимает правой кнопкой мыши по значку в трее и выбирает пресет из списка
- **THEN** выбранный пресет немедленно применяется, а отметка активности перемещается на выбранный пункт.
