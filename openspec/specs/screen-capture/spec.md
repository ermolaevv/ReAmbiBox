# screen-capture Specification

## Purpose
Предоставляет аппаратный захват кадров рабочего стола в реальном времени через Windows DXGI Desktop Duplication API с минимальными задержками и поддержкой мультимониторных систем.

## Requirements

### Requirement: Захват рабочего стола через DXGI
Система SHALL / ДОЛЖНА выполнять непрерывный захват кадров указанного монитора с использованием Windows Desktop Duplication API (Direct3D 11) без блокировки основного потока приложения.

#### Scenario: Успешный захват кадра
- **WHEN** запущен сервис подсветки для выбранного монитора
- **THEN** система получает указатель на текстуру кадра в видеопамяти с целевой частотой (до 120 FPS) и временем кадра менее 16 мс.

#### Scenario: Смена разрешения экрана или отключение монитора
- **WHEN** разрешение монитора изменяется или сессия рабочего стола переключается (UAC/Winlogon)
- **THEN** система корректно пересоздает объект дупликации DXGI без аварийного завершения работы.

### Requirement: Преобразование форматов пикселей
Система SHALL / ДОЛЖНА преобразовывать текстуры DXGI формата BGRA8 (и HDR-форматов FP16/R10G10B10A2) в непрерывный RGB-буфер для последующего анализа зон.

#### Scenario: Корректное извлечение RGB-компонентов
- **WHEN** захвачен кадр стандартного формата DXGI_FORMAT_B8G8R8A8_UNORM
- **THEN** система конвертирует необходимые регионы в RGB24 байты с корректным цветовым диапазоном.
