# system-tray Specification

## Purpose
Обеспечивает фоновое присутствие приложения в области уведомлений Windows (системный трей), быстрый доступ к управлению подсветкой через контекстное меню и индикацию статуса.

## Requirements

### Requirement: Интеграция с областью уведомлений Windows
Приложение SHALL / ДОЛЖНО создавать иконку в системном трее Windows при запуске в фоновом режиме без необходимости постоянного отображения консольного окна.

#### Scenario: Успешное создание иконки в трее
- **WHEN** приложение запускается в фоновом режиме
- **THEN** в области уведомлений Windows появляется иконка ReAmbiBox с всплывающей подсказкой текущего статуса.

#### Scenario: Клик левой кнопкой мыши по иконке трея
- **WHEN** пользователь нажимает левой кнопкой мыши на иконку в трее
- **THEN** в браузере по умолчанию открывается веб-панель управления ReAmbiBox (`http://localhost:3637`).

### Requirement: Контекстное меню системного трея
Приложение SHALL / ДОЛЖНО отображать контекстное меню при нажатии правой кнопкой мыши на иконку в трее с ключевыми действиями управления.

#### Scenario: Вызов контекстного меню
- **WHEN** пользователь нажимает правой кнопкой мыши на иконку трея
- **THEN** открывается меню с пунктами: «Включить/Выключить подсветку», «Открыть панель управления», «Автозагрузка с Windows» и «Выход».

#### Scenario: Завершение работы через меню трея
- **WHEN** пользователь выбирает пункт меню «Выход»
- **THEN** светодиоды гаснут, открытый COM-порт корректно закрывается, и процесс приложения завершается.
