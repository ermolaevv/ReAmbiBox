# zone-editor Specification

## Purpose
Предоставляет пользователю интерактивный графический оверлей прямо поверх рабочего стола для визуальной настройки расположения, размеров и порядка светодиодных зон.

## Requirements

### Requirement: Полноэкранный прозрачный оверлей настройки зон
Система SHALL / ДОЛЖНА открывать полупрозрачное окно поверх всех окон на выбранном мониторе, визуализируя текущие прямоугольные зоны захвата с их номерами и границами.

#### Scenario: Активация режима калибровки зон
- **WHEN** пользователь в интерфейсе нажимает кнопку «Настроить зоны»
- **THEN** открывается полноэкранный полупрозрачный холст с отображением всех активных зон и возможностью изменения их размеров и координат мышью.

### Requirement: Мастер автоматической расстановки зон (Zone Wizard)
Система SHALL / ДОЛЖНА поддерживать быструю генерацию типовых сеток подсветки по периметру монитора с указанием количества диодов (сверху, снизу, слева, справа, пропуск подставки).

#### Scenario: Автоматическая генерация периметра
- **WHEN** пользователь указывает общее количество диодов (например, 60 штук) и формат распределения
- **THEN** система равномерно распределяет зоны по периметру экрана с корректным направлением обхода (по часовой стрелке или против).
